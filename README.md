# GitHub Actions

A central repository to store github actions that I use across different project repositories.

## Actions

| Name         | Description                                                                |
| ------------ | -------------------------------------------------------------------------- |
| Ansible Lint | Lint Ansible playbooks and roles                                           |
| PR Labeler   | Label PRs based on which files changed                                     |
| Shellcheck   | Runs [Shellcheck](https://github.com/koalaman/shellcheck) on shell scripts |
